# 論文・学会発表への道筋：調査用目次

状態：実調査・本文執筆未開始。以下は確認項目であり、投稿資格や採択を保証しません。

1. IPSJ研究会・全国大会：発表資格、会員・学位・大学所属の必須性、原稿・発表条件。
2. 査読会議・workshop・journal：査読方式、投稿資格、費用、締切、著者規定。
3. arXiv：査読媒体ではない点と登録・endorsement条件。
4. 所属表記：独立研究、企業勤務との関係、社内許可、権利、利益相反。
5. 独立研究者・企業engineerの採択例：一次proceedingsと当時所属から2〜3件確認。
6. AI執筆支援、研究倫理、再現性、匿名査読と公開repoの両立。
