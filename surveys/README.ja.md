# サーベイノート

コンピュータサイエンス／AIセキュリティの論文・研究記事の読書記録。各ファイルは[サーベイ記録テンプレート](template.ja.md)の項目に沿い、**一次資料確認／本文精読／再現**を区別して記録する。テーマを選んでください。

- [AIエージェントの安全性・逸脱行動](agent-safety/README.ja.md)（論文2本＋研究記事1本）: AIエージェントが権限外の行動をとるか、実際のワークフローがどう攻撃されうるか。
- [おとり・欺瞞とLLMシステム防御](deception-defense/README.ja.md)（2本）: 偽の証拠やおとりモデルで、悪意あるエージェントや要求を誘導・隔離する研究。
- [コーディングエージェント・コードレビュー・開発現場](coding-agents/README.ja.md)（論文6本＋研究記事1本）: AIコーディング支援・自動修復・自動レビューのベンチマークと企業での実証研究。
- [職場での人とAIの協働](human-ai-collaboration/README.ja.md)（2本）: AIの同僚に人が何を求めるか、エージェントツールが待ち時間や注意をどう扱うべきか。
- [セキュリティ・ガバナンス（プライバシー・組織ポリシー・暗号アジリティ）](security-governance/README.ja.md)（2本）: GenAI利用と暗号移行をめぐる、組織・ポリシー面のセキュリティの問い。
- [LLM推論基盤と費用対効果](llm-infrastructure/README.ja.md)（2本）: LLM推論のハードウェア選択、スケジューリング、エージェントのKVキャッシュ制御。
- [クラウドの耐障害性・SRE](cloud-resilience/README.ja.md)（1本）: AWS複数アカウントの障害実験と復旧判定。実測・再現は未確認。
- [イベント・技術記事・仕事／労働研究](articles/README.ja.md)（記事4本＋学術論文1本）: 仕事・労働のCHI論文を記事と区別して収録。

研究記事も同じ記録項目で整理するが、査読論文・プレプリントとは区別して件数を示す。

## 研究メモの原則

- 実験を行っていない場合は「再現済み」と記載しない。
- 論文のシミュレーション結果を、実運用の攻撃成功と混同しない。
- 引用文献の一次URLと確認状態を必ず残す。
- すべてのノートに日本語版（`*.ja.md`）を用意する。

## ファイルの置き場所

論文は `surveys/<テーマ>/<年>-<スラッグ>.md`、日本語版は `<スラッグ>.ja.md`。各テーマのフォルダに、そのテーマのノート一覧のREADMEがある。計画・確認票・全読書一覧は [docs/](../docs/reading-list.ja.md) にある。
