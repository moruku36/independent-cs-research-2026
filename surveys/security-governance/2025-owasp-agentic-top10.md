# OWASP Top 10 for Agentic Applications

- Source: [original article](https://genai.owasp.org/2025/12/09/owasp-top-10-for-agentic-applications-the-benchmark-for-agentic-security-in-the-age-of-autonomous-ai/)
- Published: 2025-12-09
- Type: OWASP community framework announcement.
- Scope: primary article checked on 2026-10-30 JST; linked studies, implementations and incident claims were not independently reproduced.

## What it says

The article organizes agent risks into ten categories: goal hijack, tool misuse, identity and privilege abuse, supply chain vulnerabilities, unexpected code execution, memory poisoning, insecure inter-agent communication, cascading failures, human trust exploitation and rogue agents. It uses incidents as illustrative examples and positions the taxonomy as shared language for security work.

## Practical application

Map each category to actual assets, owners, existing controls and a test scenario. Prioritize by impact and likelihood rather than treating ten categories as a certification checklist.

## Limits and next check

This is guidance or an announcement, not an independent evaluation. Validate controls against the actual architecture and deployment; no tests or implementation were performed for this note.
