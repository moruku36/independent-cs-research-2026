# CSA：MAESTRO 脅威モデリング

- 原文：[記事](https://cloudsecurityalliance.org/blog/2025/02/06/agentic-ai-threat-modeling-framework-maestro)
- 公開日：2025-02-06
- 種別：Cloud Security Allianceによるフレームワーク提案。
- 確認範囲：2026-10-30（日本時間）に一次記事の本文を確認。リンク先の研究・実装・事例の独立検証や再現は未実施。

## 何を述べているか

エージェントシステムを7層に分解し、各層の脅威と層をまたぐ攻撃連鎖を洗い出す。モデル、データ、フレームワーク、インフラ、セキュリティ、エコシステムを一体として捉える。例えばインフラ侵害からデータ汚染、エージェントの誤動作につながる経路を考える。

## 実務への活かし方

実システムの構成図と信頼境界を書き、層をまたぐ攻撃経路、影響、担当者、対策を記録する。モデルやツール、権限が変わったときに見直す。

## 限界と次に確認すること

指針・発表記事であり、対策の有効性を独立検証した結果ではない。実際の構成と運用条件に照らして確認する必要がある。このノート作成時に実装・検証は行っていない。
