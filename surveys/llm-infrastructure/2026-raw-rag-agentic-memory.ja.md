# Is Complex Agentic Memory Always Needed? — Raw-RAGとエージェント記憶の比較

## 概要

- **何についてのものか**：長期会話の外部記憶に、要約・事実更新・グラフ構築などの複雑さが必要かを調べるプレプリント。
- **何を述べているか**：生の会話履歴を検索・再ランキングするRaw-RAGが、Full-contextを除く記憶システム比較の7条件中6条件で最高スコアを報告する。
- **留意点**：公開データによるオフライン評価であり、全エージェント・実運用・削除要件への優位を示さない。コード検証・再現は未実施。

## 人・PMO向けの要点

複雑な記憶管理を導入する前に、原文の検索を十分に調整した比較対象が必要、という研究である。「RAGなら何でもよい」「記憶管理は不要」と一般化しない。検索できた情報を読む能力と、必要な根拠をそもそも渡せる能力を分けて評価する視点が有用である。

## 手法と評価の読み方

日時・話者・本文を残し、標準では256トークン、重複32トークンで分割する。埋め込み検索で128候補を取り、cross-encoderで15件に絞ってreaderへ渡す。抽出した事実への置換やLLM要約は標準パイプラインに含めない。

**15件は入力15チャンク分の固定トークン上限ではない。** 会話ターンへの展開で入力長が増え、ベンチマークごとの表示規則も異なる。MEMEでは検索後に原文順へ並べ、MemoryAgentBenchではターン展開を無効にするなどの調整がある。5,000トークン制御は標準設定とは別の実験である（付録B・C）。

LoCoMoとLongMemEvalには既報スコアと本研究での評価が混在し、付録Aで対応条件を区別している。「全方式を完全に同じソフトウェア・モデル設定で再実行」とは読まない。

## 主要結果

| 観点 | 著者報告 | 読み方 |
|---|---|---|
| 主比較 | 記憶システムの7条件中6条件で首位、最良の比較方式に0.13–5.53ポイント差 | Full-contextを除く。全下位タスクの首位ではない |
| 例外 | DeepSeek-V4-FlashのMEMEではRaw-RAG 43.19%、MemMachine 44.71%、Full-context 63.17% | 明確な例外を含む |
| 再ランキングの除去 | MemoryAgentBenchで48.32%→44.40% | 「単純な検索」でも検索設計は重要 |
| 記憶管理の追加 | 同条件で事実抽出・要約追加・グラフ拡張はいずれも総合点を下げた | 試した実装についての結果であり、方式全体の否定ではない |
| 取り込み＋検索時間 | MEMEの10エピソード・110質問で305.91秒 | 回答生成・評価を含まない。全体応答時間やAPI請求額ではない |

## なぜ効くのか：根拠の量と関係を残す

著者は、答えの値に加え、その値が現在有効である理由や依存関係を原履歴が残せる点を分析している。根拠が十分に届く割合（coverage）と、届いた場合に正答する割合（utilization）を区別する。

全保存記憶から正解情報を使って選ぶcomplete-store実験も、生の根拠との差を解消しない。ただし、このoracleは通常運用できる検索器ではなく、差のすべてを取り込み時の情報損失と断定できない。証拠の組み立て・位置の影響も残る（§5、付録A.5・C.5）。

また、Mem0の更新・削除を制限した診断はQA精度の比較である。**古い事実を無効化して答えないことと、保存データを完全に削除することは別要件**であり、この結果で実削除を省略してよいとはならない。

## 当リポジトリからの検討・未実施の確認計画

1. 公開または合成の小規模会話を固定し、訂正・期限・削除指示・連鎖する変更を含む質問と正解根拠を先に作る。個人の会話ログを使わずに始める。
2. 同じreader・質問・予算で、原文検索、要約検索、原文＋要約の併用を比較する。埋め込みモデル、reranker、候補数、証拠トークン数、順序を記録する。
3. 正答率だけでなく、必要根拠・依存経路の回収、古い情報の誤採用、回答保留、取り込み・検索・生成の各時間を分けて測る。
4. 無料枠・既存ローカル環境の範囲で検索部分を検証する。モデルやハードウェアを変更した場合は探索実験とし、論文の数値再現とは呼ばない。
5. 権限分離、保持期間、削除後の検索不能・保存物の削除を別途試験する。要約や派生インデックスへの変更反映も確認する。

採用判断では、まず原文保持RAGを比較基準として用意し、構造化によって何が改善するかを測る。低いQAスコアだけで、運用上必要な更新・削除・監査機能を外さない。以上は当リポジトリの検討案であり未実施。
