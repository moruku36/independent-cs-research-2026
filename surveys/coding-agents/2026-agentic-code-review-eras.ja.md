# 人中心からエージェント型コードレビューへ — 生成AIの世代がレビュー品質に与える影響（102万PR・207プロジェクト）

## 人・PMO向けの要点

- **何が分かった**：GitHubの207プロジェクト・約102万件のレビュー済みPRを、AIレビュアー導入前（pre-LLM）、LLM補助（LLM期）、AIエージェント（エージェント期）の3期で比較した。AIレビュアーの導入の仕方は3種に分かれた（段階的46%、LLM先行22%、エージェント急速導入32%）。段階的導入とエージェント急速導入ではエージェント期にレビューが速くなったが（−2.5／−4.5日/KLOC）、レビューの質の指標（レビュースメル）の有意な改善は確認されなかった。LLM先行導入ではスメルが増えた。
- **何に使える**：AIレビュアーを一律でなく選択的に導入する判断材料。「同じレビュアーへの依存（Review Buddies）」「大きな変更の集中」を、AI導入後の監視項目にする案。
- **注意点**：観察研究で、論文自身も回帰分析は説明的で因果ではないと述べる。「質」は6種のレビュースメルのうち検出ルールで測れるものだけで、バグ検出の正確さやコメントの有用性は測っていない。エージェント期は時間区分で、全レビュアーがエージェントとは限らない。表6の数値は取得テキストが崩れており、本記録では本文の記述のみを使った。

### 主張と、記録者の推論の分離

**論文の主張**

- 段階的導入とエージェント急速導入は、エージェント期にレビューが速くなるが、スメルの改善はない。LLM先行導入はスメルが増え（+8.0／+4.4）、効率の改善はない。
- どの協働パターンも、効率と質の両方で人のみのレビューを一貫して上回らない。AI関与パターンの多くは、人のみよりスメル（特にReview Buddies）が多い。
- 協働パターンは、LLM・エージェントが参加した後のレビュー効率の「最も強い説明要因」（要旨）。ただしRQ3の要約は、従来要因も重要で、協働パターンは「強い要因の一つ」と書く（記述に濃淡あり）。
- 含意（§IV）：PR文脈と観測した効率・品質に基づき、AIレビュアーを選択的に導入する。PRを人主導にするか、LLMの要約にするか、エージェントの検査を入れるかの判断を支援する文脈対応ツール。AIと従来のレビュー慣行の併用。マルチエージェントで、単一の既定AIレビュアーへの依存を避ける案。開発者の判断理由の調査、PR文脈を反映したベンチマーク。

**記録者の推論**（論文の主張ではない）

- レビュー効率は「決定までの日数÷変更規模」で、変更が小さいPRは分母が小さくなり値が大きくなる。サイズ分布の違いが効率比較に影響し得るが、本文で感度分析は確認できなかった。
- スメル指標は、Review Buddiesが「同一レビュアー（人・LLM・エージェント）が著者のPRの50%以上をレビュー」と定義されるため、導入が1つの既定ボットだけで成り立つ場合に高くなりやすい。AIレビュアーがほぼ全PRを自動レビューするプロジェクトで増えるのは、定義上の帰結の面もあり、「質の低下」とは限らない。論文もこの指標を「質のリスク」の指標と呼んでいる。
- 「質」の評価に、バグ検出率やコメントの有用性は含まれない。効率が上がり質が改善しない、という論文の結論は、この指標の範囲での結論である。
- 時期は、プロジェクトごとの「最初のAIレビュアー参加」で定義され、同時期の他の要因（プロジェクト成熟、ツール変更、規模）は統制されていない（本文でそのような統制は確認できなかった）。

## English

From Human-Centric to Agentic Code Review (arXiv:2607.13196v1, cs.SE, submitted 14 Jul 2026; preprint, venue unconfirmed) studies about 1.02 million reviewed pull requests from 207 GitHub projects across pre-LLM, LLM-assisted and agentic review eras. Three adoption practices are found (Gradual 46%, Rapid LLM 22%, Rapid AI Agent 32%). Gradual and Rapid AI Agent adoption show faster reviews in the agent era (−2.5 and −4.5 days/KLOC) without significant improvement in review smells; Rapid LLM adoption shows more smells (+8.0 and +4.4 points). Most AI-involved collaboration patterns show more review smells than human-only review, driven by Review Buddies. The regression analysis is explanatory, not causal.
