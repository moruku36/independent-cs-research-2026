# From Approval to Abuse: Privilege Escalation Attacks on Harness-Protected Coding Agents

- Preprint: [arXiv:2610.22987v1](https://arxiv.org/html/2610.22987v1)
- Access and verification: Primary HTML: abstract and main sections checked. [Material checked](https://arxiv.org/html/2610.22987v1). No independent replication or code review.
- Recorded: 2026-10-30 JST.

## Question and method

The authors show that hostile repository context can induce a coding agent to request a broadly reusable permission. The target rule was requested in 58% of experimental instances; conditional on approval, 47 of 58 eligible cases (81.0%) silently achieved the attacker's goal. The second figure is conditional, not the success rate across all cases.

## Practical application

Prefer scoped, time-limited permissions and inspect reusable command prefixes; periodically review and remove obsolete allow rules.

## Limits and follow-up

Results are author-reported and apply to the studied configurations. The experiments were not independently reproduced. Check applicability to actual tools, permissions and deployment.
