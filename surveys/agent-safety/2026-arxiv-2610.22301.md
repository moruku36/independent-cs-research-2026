# My Credentials, Please: Detecting Filesystem Capability Laundering in MCP Servers at Scale

- Preprint: [arXiv:2610.22301v1](https://arxiv.org/html/2610.22301v1)
- Access and verification: Original HTML and abstract unavailable through retrieval; abstract reproduced on third-party site checked. [Material checked](https://borowiecki.dev/abs/2610.22301). No independent replication or code review.
- Recorded: 2026-10-30 JST.

## Question and method

The abstract describes MCP servers whose actual filesystem access exceeds their declared tool purpose. Of 4,806 triaged servers, 787 had filesystem capabilities despite non-filesystem classifications; the paper reports 150 vulnerable instances in dynamic tests. These are distinct denominators and do not imply 16.4% of all 21,097 catalogued servers are vulnerable.

## Practical application

Run MCP servers under isolated identities with minimum filesystem mounts and inspect the actual server process permissions, not only tool descriptions.

## Limits and follow-up

Results are author-reported and apply to the studied configurations. The copied abstract is provisional; verify against the exact v1 full text before relying on the details. Check applicability to actual tools, permissions and deployment.
