# The Innocent Courier: Covert Exfiltration Through Legitimate LLM Web Fetching

## Question and method

According to the abstract, locally running malicious software unable to reach the internet directly can embed a secret in a URL and persuade the model to fetch it for a seemingly legitimate task. An attacker-controlled DNS or web server then receives the encoded secret. The reported 79.7% attack success concerns the authors' eleven open-parameter models and setup.

## Practical application

Treat agent HTTP and DNS access as possible egress paths. Restrict destinations, avoid secret-bearing URLs and test with synthetic data.

## Limits and follow-up

Results are author-reported and apply to the studied configurations. The copied abstract is provisional; verify against the exact v1 full text before relying on the details. Check applicability to actual tools, permissions and deployment.
