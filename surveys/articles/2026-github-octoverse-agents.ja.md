# Octoverse 2026：AIエージェントとGitHubの開発動向

## 3行概要

- GitHubが自社プラットフォームの活動データをまとめた企業レポート。
- コミットやPRが増え、検出可能なエージェントによるPR着手も増えている。
- 活動量の相関から、生産性・品質の改善やAIによる因果関係は断定できない。

## 出典と確認範囲

[GitHub Blog](https://github.blog/news-insights/octoverse/octoverse-commits-pushes-reach-new-highs-in-2026-as-developers-build-with-agents/)、GitHub Staff、2026-10-28。記事本文とMethodologyを確認。企業の観測・分析記事であり、学術論文ではない。生データや集計処理は独立検証していない。

## 調査結果と条件

- 集計期間は2025-10-01〜2026-09-30。断りのない全体指標は公開・非公開リポジトリを含む。過去年も同一の定義・期間で再計算されている。
- 期間中、pushは179億回、commitは343億件、マージされたPRは13億件。1回のpushには複数commitを含められるため単純に同一視しない。
- 2026年9月はPRの40%超が検出可能なエージェントの初稿で始まり、3月は17%。未検出の利用がありうる。
- その年に新規作成されたリポジトリでは、エージェント設定ファイルありの群は、なしの群の平均8倍のcommitを記録。設定がない場合もAIを利用している可能性があり、選択バイアスを含む観測比較である。
- 9月に自分でモデルを選択したCopilot利用者の61%が複数モデルを利用。自動選択の利用者全体を意味しない。産業分類は公開リポジトリの標本に対するモデル推定。

## 結論と実務への応用

GitHubはエージェント利用の普及とレビュー・モデル選択の重要性を論じる。個人や会社では、変更件数だけで評価せず、レビュー時間、リードタイム、修正後の障害、手戻り、コスト、権限や秘密情報の管理も併せて観察するとよい。複数モデルの使い分けはタスク別に小さく試し、実測で判断する。

## 限界

GitHub上の集計であり、業界全体の実態を代表すると限らない。検出されたエージェント活動は利用全体の完全な把握ではない。設定ファイルとcommit量の差は因果関係を示さず、commitやPRの数は利用者価値・品質・実効的な生産性そのものではない。
