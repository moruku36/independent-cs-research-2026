# Octoverse 2026: GitHub activity and development with agents

## Overview

- GitHub reports activity observed on its own platform.
- Commits and pull requests increased alongside detectable agent involvement.
- Observational activity counts do not establish causality, productivity or quality gains.

## Source and scope

[GitHub Blog](https://github.blog/news-insights/octoverse/octoverse-commits-pushes-reach-new-highs-in-2026-as-developers-build-with-agents/), GitHub Staff, 28 October 2026. Article and methodology checked; raw data and calculations not independently verified. This is a company report, not an academic paper.

## Findings

- The reporting window is 1 October 2025–30 September 2026. Unless stated otherwise, metrics include public and private repositories; past years were recalculated using matching definitions and windows.
- GitHub reports 17.9 billion pushes, 34.3 billion commits and 1.3 billion merged pull requests. A push can contain multiple commits.
- In September, over 40% of PRs began with a detectable agent's first draft, up from 17% in March. Some agent use may be missed.
- Among repositories created in the year, those with an agent configuration file averaged eight times as many commits as those without. Repositories without such files may still use AI; this association does not show AI caused the difference.
- In September, 61% of Copilot users who selected a model themselves used multiple models. Industry classifications use model estimates over public-repository samples.

## Practical use and limitations

Combine activity counts with review time, lead time, incidents, rework, costs, permissions and secret handling. Experiment with model choices for different tasks and measure results. Platform telemetry is not necessarily representative of all development; commits and PR counts alone are not delivered value or quality.
