## 読むときの注意

論文・企業記事・個人の実践記事・企業開示は、資料の種類を区別して記録しています。一次資料の確認範囲、限界、再現の有無は各ノートを参照してください。実務への適用案は、実施・検証済みの成果とは限りません。

研究計画は初期段階で、独自研究の検証や再現実験は未実施です。発表資格、採択例、経歴や所属の表記は未確定です。

公開情報を扱い、会社内部情報、私信、秘密、非公開の個人情報は掲載しません。公開前の誤認防止のため、本プロジェクトの構成・主張・図表・調査結果の他媒体への転載・再利用・引用・要約はお控えください。
