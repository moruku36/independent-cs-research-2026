# Independent CS Research 2026

個人・企業勤務者がコンピュータサイエンスの研究を進め、論文・学会発表につなげるための公開ノートです。公開情報に基づく発表経路、研究候補、AI論文の読書記録と活用案を今後蓄積します。

**2026-10-10現在：初期スケルトンのみ。実調査・本文執筆は未開始、研究候補は新規性未検証・実験未開始です。発表資格・採択例・経歴・所属はまだ確定していません。**
